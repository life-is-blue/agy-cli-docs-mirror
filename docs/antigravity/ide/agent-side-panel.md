# Agent side panel

Available on: Antigravity IDE

Use the **Agent** side panel in the editor to work directly with the agent. From the panel header and prompt input, you can start new conversations, browse conversation history, reference context with `@`, run workflows with `/`, attach images, switch [agent modes](/docs/agent-settings), and select between [different models](/docs/models).

![The Agent side panel in the editor showing conversation history controls, the prompt input box, the mode selector, and the model picker](/assets/image/docs/editor/editor_agent_panel.png)

As your conversation progresses, the **Agent** side panel displays step-by-step progress updates and edited files for each task, while the bottom toolbar above the prompt input lets you track generated [artifacts](/docs/artifacts), running terminal processes, and open file changes via **Review Changes**.

![An active conversation in the Agent side panel showing task progress updates, edited files, and the bottom toolbar with artifacts, terminal processes, and Review Changes controls](/assets/image/docs/editor/agent_panel_toolbar.png)
