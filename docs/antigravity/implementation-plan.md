# Implementation plan

Available on: Antigravity App, Antigravity IDE

The agent uses the implementation plan artifact to architect changes within your codebase to accomplish a task. These plans contain technical details on what revisions are necessary and are designed for you to review.

Note

**Planning mode**: You can explicitly trigger structured planning and generate an implementation plan artifact at any time using the [`/plan`](/docs/plan) slash command.

The following example shows a plan generated by the agent:

![The Antigravity App with a /plan request and the agent's reply on the left, ending in an Implementation Plan card with a Proceed button, and the implementation plan for adding a GET /v1/bookmarks/ endpoint open in the side panel on the right, showing its goal description, proposed changes, and a diff](/assets/image/docs/artifacts/artifact-implementation-plan.png)

The agent requests your review on the implementation plan before making the changes needed to complete your task, whatever your [artifact review policy](/docs/artifact-review) is. Click **Proceed** on the plan’s card in the conversation to immediately continue with the agent’s plan.

![The agent's reply in the Antigravity App asking whether the plan looks good, followed by an Implementation Plan card with a blue Proceed button and its keyboard shortcut](/assets/image/docs/artifacts/artifact-implementation-plan-proceed.png)

Often, the agent creates a plan that differs slightly from what you want. Antigravity supports commenting on these artifacts so you can provide feedback to the agent for any reason, such as reducing the scope of changes, using a different tech stack, or correcting any discrepancies.

![An implementation plan open in the side panel of the Antigravity App with two passages highlighted. A comment box under the second highlight reads Use the same 404 body as DELETE so clients only handle one shape, with Cancel and Add Comment buttons, and the message box shows a 1 Comment chip](/assets/image/docs/artifacts/artifact-implementation-plan-comments.png)

Your comments are attached to your next message and appear as a chip, such as **2 Comments**, above the message box. Hover over the chip to see all comments. You can still click **Proceed** to continue with the agent’s plan and your comments, or send a message to give feedback instead of proceeding directly.

![The pointer over a 2 Comments chip above the message box in the Antigravity App, with a preview that lists both comments on the Implementation Plan and the line each one refers to](/assets/image/docs/artifacts/artifact-implementation-plan-submit-comments.png)

Once you proceed or submit a review, the agent continues its work, either iterating on the implementation plan and requesting another review or beginning implementation.

![The conversation in the Antigravity App after clicking Proceed, showing Proceeded with 2 Comments, the agent's summary of the endpoint and tests it added, a Walkthrough card, and a 2 files changed +30 -0 row with a Review button](/assets/image/docs/artifacts/artifact-implementation-plan-proceeded.png)
