# Learn with Antigravity

Effective agentic development starts with how you frame problems, manage context, and verify outputs. Use **Learn** to build practical AI engineering fundamentals. Then apply them in step-by-step build guides you can launch directly in Google Antigravity.

## Choose your path

| Your goal | Start here | What you get |
| --- | --- | --- |
| **New to coding agents** | [AI foundations](#ai-foundations) in order | Core mental models for prompting, context hygiene, tools, and verification. |
| **Learn by building** | [Build a playable 3D browser world](/docs/learn/build-3d-browser-world) | A Three.js game built from an empty folder in one `/swarm` prompt. |
| **Scaling existing workflows** | [Context windows and tokens](/docs/learn/context-and-tokens) and [Verification and guardrails](/docs/learn/verification-and-guardrails) | Antigravity context commands (`/compact`, `/btw`), sandboxing, hooks, and review gates. |
